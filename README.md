# Nebula Vape Co.

A modern, premium vape shop static website inspired by eVapeLot. Built with React,
TypeScript, Vite, Tailwind CSS, React Router, and local JSON product data.

## Features

- Dark luxury theme with purple and blue gradient accents
- Responsive pages for home, catalog, product details, categories, new arrivals, about, and contact
- Static JSON product catalog
- Product search, category filtering, brand filtering, and sorting
- Reusable components for navigation, hero, cards, grids, testimonials, newsletter, and footer

## Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```
